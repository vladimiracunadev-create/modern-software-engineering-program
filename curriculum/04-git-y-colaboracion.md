# Módulo 04 — Git y colaboración

## Objetivos

- construir cambios pequeños, trazables y revisables;
- resolver conflictos conservando intención;
- usar ramas, revisiones y versiones;
- comunicar contexto y riesgos.

## Contenidos

Modelo de objetos Git; commits; ramas; merge y rebase; etiquetas; `.gitignore`; revisión; convenciones; changelog; SemVer; propiedad de código; documentación y decisiones.

## Laboratorio

Realiza una mejora vertical en una rama: requisito, prueba que falla, implementación, documentación y ADR si cambia arquitectura. Simula un conflicto y explica cómo validaste la resolución.

## Seguridad

Practica prevención y respuesta ante secretos comprometidos. Borrar el archivo del último commit no elimina automáticamente su historia ni revoca la credencial.

## Criterio

Otra persona puede entender, revisar, probar y revertir el cambio.
