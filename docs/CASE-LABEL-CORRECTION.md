# Corrección de etiquetas ficticias en los casos de aprendizaje

## Decisión

Las etiquetas editoriales **Pulso, Faro, Nexo, Atlas, Brújula, Prisma, Orbe,
Lupa** y **Constelación** se retiran de la presentación educativa de las Partes
01–09. No son conceptos técnicos, estándares ni productos reales. Su presencia
al comienzo de una clase obligaba a descifrar un nombre antes de comprender el
problema profesional y podía producir una falsa sensación de continuidad.

El contenido y los casos se conservan. Solo cambia la denominación:

| Alias anterior | Descripción funcional usada ahora |
|---|---|
| Pulso | analizador local de eventos |
| Faro | kit de diagnóstico multiplataforma |
| Nexo | petición observable de extremo a extremo |
| Atlas | modelo de decisión diagnóstica |
| Brújula | CLI diagnóstica |
| Prisma | motor de reglas comparado |
| Orbe | biblioteca de estructuras y algoritmos |
| Lupa | entorno reproducible de diagnóstico |
| Constelación | SDK y CLI versionados |

## Fundamento pedagógico

La corrección reduce conocimiento incidental: el estudiante ve primero la
función del sistema y puede relacionarla con el objetivo, la práctica y la
evidencia. Esto aplica el principio del estándar interno de explicar contexto y
mecanismo antes que herramienta o decoración. También hace explícita la
conexión con [How People Learn II](https://nap.nationalacademies.org/catalog/24783/how-people-learn-ii-learners-contexts-and-cultures),
que sitúa el aprendizaje en el conocimiento previo y el contexto, y con
[ICAP](https://icap.education.asu.edu/research), porque la actividad debe llevar
a predecir, explicar y contrastar el mecanismo, no a recordar el nombre de un
caso ficticio.

Esta tabla conserva la trazabilidad histórica sin mantener los alias como
requisito cognitivo dentro de las clases.
