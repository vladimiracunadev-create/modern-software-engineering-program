# Gobierno del programa

## Decisiones

- Corrección local: responsable del repositorio propietario.
- Cambio contractual: ADR y revisión de consumidores.
- Nuevo dominio o ruta: RFC en la suite.
- Tecnología nueva: ficha oficial y laboratorio antes de promoverla al núcleo.
- Seguridad crítica: prioridad sobre la hoja de ruta normal.

## Estados de cobertura

| Estado | Significado |
| --- | --- |
| Catalogado | identificado y con fuente |
| Guiado | existe material pedagógico |
| Ejecutable | laboratorio reproducible |
| Verificado | pruebas automáticas y revisión |
| Integrado | participa en proyecto transversal |
| Operable | incluye telemetría, recuperación y runbook |

## Calidad editorial

Lenguaje claro, acrónimos definidos, ejemplos sintéticos, resultados esperados, rutas alternativas y fuentes primarias. Las afirmaciones temporales llevan fecha.

## Revisión periódica

Revisar trimestralmente enlaces y estado del núcleo, semestralmente rutas y proyectos, y después de cada versión mayor los laboratorios afectados. La revisión no actualiza automáticamente código: abre una decisión trazable.
