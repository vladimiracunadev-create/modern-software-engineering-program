# Modelo de aprendizaje

## Ciclo

1. **Contexto:** por qué importa.
2. **Concepto:** modelo transferible.
3. **Demostración:** caso pequeño explicado.
4. **Práctica guiada:** pasos y comprobaciones.
5. **Fallo controlado:** diagnóstico.
6. **Transferencia:** otro lenguaje, motor, framework o dominio.
7. **Integración:** fragmento vertical.
8. **Reflexión:** decisión, límites y portafolio.

## Niveles

Reconocer → aplicar → diagnosticar → transferir → diseñar → operar → liderar.

## Inclusión

- objetivos y tiempos explícitos;
- instrucciones fragmentadas;
- glosario y mapas visuales;
- alternativas de evidencia escrita, oral, visual y ejecutable;
- datos y entornos pequeños;
- retos opcionales;
- retroalimentación por criterio;
- recuperación de aprendizajes sin bajar el objetivo esencial.

## Docencia

Una clase combina ciclos breves de explicación, predicción, práctica y comprobación. En grupos con desinterés o conflicto, se priorizan problemas auténticos, roles claros, evidencia visible, opciones acotadas y normas consistentes. La disciplina no sustituye apoyo especializado cuando se requiere.
