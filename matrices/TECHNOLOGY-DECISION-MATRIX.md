# Matriz de decisión tecnológica

Define pesos antes de evaluar candidatos.

| Criterio | Pregunta | Evidencia | Peso |
| --- | --- | --- | ---: |
| Producto | ¿resuelve el flujo prioritario? | prototipo y prueba de usuario | |
| Calidad | ¿cumple atributos medibles? | prueba, medición, SLO | |
| Equipo | ¿puede construir y operar? | experiencia y plan de aprendizaje | |
| Seguridad | ¿defaults y controles suficientes? | modelo de amenazas | |
| Datos | ¿preserva invariantes y ciclo? | modelo, transacción, recuperación | |
| Integración | ¿contratos y ecosistema encajan? | fragmento vertical | |
| Operación | ¿se observa y recupera? | runbook y ejercicio | |
| Evolución | ¿se actualiza y migra? | guía, prueba y ADR | |
| Dependencia | ¿existe salida razonable? | prototipo o plan de migración | |
| Costo total | ¿construcción y operación son viables? | modelo de capacidad y costos | |

La suma ayuda a discutir; no convierte incertidumbre en precisión falsa. Documenta supuestos y análisis de sensibilidad.
