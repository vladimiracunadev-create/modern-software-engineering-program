Definición

Fracción de consultas con el fragmento correcto entre los k primeros.

Definición de trabajo de SE-594 — Embeddings, recuperación y agentic RAG.

Por qué importa

La clase donde se define, SE-594 — Embeddings, recuperación y agentic RAG, existe con este propósito: la clase existe para que construyas la recuperación de información de un sistema con LLM como un componente que se mide, no como un paso de moda.

Cómo funciona

SE-594 — Embeddings, recuperación y agentic RAG no desarrolla este término en una sección propia. Lo usa como pieza de su tema: consulta la clase para el mecanismo completo.

Errores y confusiones comunes

Límites y cuándo no aplica

Las clases no fijan un límite propio para este término. Los límites del tema donde se enseña (SE-594 — Embeddings, recuperación y agentic RAG) son: El vector del experimento no es un modelo de embeddings semántico; las consultas son sintéticas y salen del propio corpus; solo hay seis consultas ajenas; no se evaluó ningún modelo de embeddings, ninguna base vectorial ni ningún producto de RAG. El siguiente paso, SE-595, sale del proceso: cómo un agente descubre y llama herramientas de otros y cómo se comunican entre sí agentes distintos con protocolos como MCP y A2A.
