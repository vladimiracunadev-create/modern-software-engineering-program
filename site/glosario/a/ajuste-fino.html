Definición

Entrenamiento adicional de un modelo base con datos de la tarea o población nueva.

Definición de trabajo de SE-605 — Ajuste fino, adaptación y costo.

Por qué importa

La clase donde se define, SE-605 — Ajuste fino, adaptación y costo, existe con este propósito: la clase existe para que decidas con números cuándo vale la pena adaptar un modelo existente, cuánto cuesta hacerlo y qué se pierde por el camino.

Cómo funciona

SE-605 — Ajuste fino, adaptación y costo no desarrolla este término en una sección propia. Lo usa como pieza de su tema: consulta la clase para el mecanismo completo.

Límites y cuándo no aplica

Las clases no fijan un límite propio para este término. Los límites del tema donde se enseña (SE-605 — Ajuste fino, adaptación y costo) son: El modelo base, las dos poblaciones y las cantidades de datos son construcciones del autor sobre un modelo lineal; las cifras de parámetros y de cómputo para modelos grandes son aritmética con una regla publicada y un rendimiento supuesto, no mediciones. No se ajustó ningún modelo de lenguaje ni se usó acelerador. El siguiente paso, SE-606, se ocupa de servir el modelo elegido: latencia, lotes y aceleradores.
