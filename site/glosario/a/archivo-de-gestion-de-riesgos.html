Definición

Conjunto de registros del análisis y control de riesgos del dispositivo.

Definición de trabajo de SE-449 — Dispositivos médicos: IEC 62304.

Por qué importa

La clase donde se define, SE-449 — Dispositivos médicos: IEC 62304, existe con este propósito: la clase existe para que entiendas cómo se organiza el desarrollo de software de un dispositivo médico y por qué su decisión central, la clase de seguridad del software, es una afirmación sobre qué puede causar el software y qué lo limita desde fuera, y no sobre cuán complejo es.

Cómo funciona

Según SE-449 — Dispositivos médicos: IEC 62304:

El software cambia después de la entrega: correcciones, mejoras, parches de SOUP. Cada cambio necesita un análisis de impacto sobre los riesgos y las pruebas, y la configuración (qué versión de cada elemento está en cada unidad) debe ser reproducible. La relación con la gestión de riesgos es bidireccional: un peligro nuevo puede generar un requisito de software, y un cambio de software puede cambiar un riesgo. Un archivo de gestión de riesgos que se hizo al principio y nunca se actualizó es una pieza de museo.

Límites y cuándo no aplica

Las clases no fijan un límite propio para este término. Los límites del tema donde se enseña (SE-449 — Dispositivos médicos: IEC 62304) son: El dispositivo, los módulos, las clases y los pesos son ficticios y del autor; el modelo de error de entrada es de un solo tipo; las normas de pago no se reproducen y no se afirma conformidad regulatoria ni revisión por una autoridad. El siguiente paso, SE-450, organiza toda la evidencia de las clases anteriores como un caso de seguridad: un argumento estructurado con trazabilidad.
