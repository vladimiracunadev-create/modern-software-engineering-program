Definición

Conjunto de comportamientos que ejercen una propiedad de aislamiento cada uno.

Definición de trabajo de SE-287 — Taller: elegir y aislar un runtime para una carga no confiable.

Por qué importa

La clase donde se define, SE-287 — Taller: elegir y aislar un runtime para una carga no confiable, existe con este propósito: el taller existe para que la elección de un runtime y de una frontera de aislamiento deje de ser una opinión y se convierta en un resultado que cualquiera puede repetir: seis comportamientos hostiles, tres formas de ejecutar código ajeno, una matriz de qué contiene cada una y una decisión por carga de trabajo con su costo.

Cómo funciona

SE-287 — Taller: elegir y aislar un runtime para una carga no confiable no desarrolla este término en una sección propia. Lo usa como pieza de su tema: consulta la clase para el mecanismo completo.

Límites y cuándo no aplica

Las clases no fijan un límite propio para este término. Los límites del tema donde se enseña (SE-287 — Taller: elegir y aislar un runtime para una carga no confiable) son: El taller probó tres candidatos con seis comportamientos en una máquina Windows; no probó contenedores, microVM, núcleo de aplicación, perfiles de llamadas de sistema ni límites de memoria del sistema operativo, y dos celdas del primer candidato quedaron sin ejecutar. El siguiente paso, SE-288, integra los candidatos en una plataforma con validación, límites, evidencia encadenada e informe firmado.
