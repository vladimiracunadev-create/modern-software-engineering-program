Definición

Una biblioteca ofrece funciones o tipos que el programa consumidor llama y compone.

Definición de trabajo de SE-109 — Biblioteca, framework, runtime, plataforma y SDK.

Por qué importa

En SE-109 — Biblioteca, framework, runtime, plataforma y SDK, el tema «Biblioteca» importa porque una biblioteca ofrece funciones o tipos que el programa consumidor llama y compone.

Cómo funciona

Según SE-109 — Biblioteca, framework, runtime, plataforma y SDK, en la sección «Biblioteca»:

Una biblioteca ofrece funciones o tipos que el programa consumidor llama y compone. El consumidor conserva el flujo principal. Una biblioteca puede traer efectos o runtime, pero debe declarar inicialización, thread safety y ciclo de vida en su API.

Ejemplo

Ejemplo de SE-109 — Biblioteca, framework, runtime, plataforma y SDK (sección «Caso conductor»):

El producto reutilizable con SDK y CLI empaqueta el motor de la biblioteca de estructuras y algoritmos como engineering_sdk, expone choose_next, una CLI y un punto de extensión. Ejecuta instalación limpia, entrada válida, configuración ausente, plugin incompatible y actualización entre dos versiones. Cambia después una sola regla o condición y revisa qué archivos, pruebas y trazas debieron modificarse. Esa superficie de cambio alimenta el proyecto final de la parte.

Errores y confusiones comunes

Errores que las clases asocian con este término (síntoma → causa → corrección):

  • El producto se anuncia como «plataforma» pero no tiene responsable ni SLO — causa: se confundió conjunto de librerías con plataforma. Corrección: escribir propiedad, soporte, cuotas y política de cambios, o llamarlo biblioteca. (SE-109)

Límites y cuándo no aplica

Lo que las clases dicen sobre dónde deja de valer este término:

  • La diferencia entre biblioteca y framework no está en el tamaño ni en el nombre sino en quién ocupa el fondo de la pila. (SE-109)
