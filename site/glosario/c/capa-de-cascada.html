Definición

Agrupación con nombre (@layer) cuyo orden de declaración decide entre estilos antes de comparar la especificidad.

Definición de trabajo de SE-229 — Plataforma web, HTML semántico y CSS.

Por qué importa

La clase donde se define, SE-229 — Plataforma web, HTML semántico y CSS, existe con este propósito: la clase existe para que trates el HTML y el CSS como un contrato con el navegador y con las tecnologías de apoyo, no como una capa de decoración: un button real ya trae foco, teclado y rol; un div con onclick obliga a reconstruirlo, y a menudo se reconstruye mal.

Cómo funciona

SE-229 — Plataforma web, HTML semántico y CSS no desarrolla este término en una sección propia. Lo usa como pieza de su tema: Las definiciones son operativas para esta clase y deben contrastarse con las especificaciones enlazadas al final.

Ejemplo

La clase no ilustra este término por separado; el ejemplo de su tema está en la sección «Ejemplo profesional» de SE-229 — Plataforma web, HTML semántico y CSS:

El formulario de entrega del caso conductor se publica con una estructura revisable: un header con nav, un main con un único h1 («Entregar tarea») y h2 por bloque, un form con dos campos, cada uno con su label for, un button type="submit" y un mensaje de estado en una región con role="status". Los colores salen de variables CSS con la razón de contraste anotada junto a cada par. La hoja usa @layer base, componentes, utilidades; de modo que un ajuste puntual no necesita subir selectores.

Errores y confusiones comunes

Las clases no registran un error exclusivo de este término. Los errores frecuentes del tema donde se enseña (SE-229 — Plataforma web, HTML semántico y CSS) son:

  • Un lector de pantalla anuncia «campo de edición» sin nombre — causa: campo con placeholder pero sin label asociada. Corrección: añadir label for con el id del campo; el placeholder no es un nombre fiable.
  • Los encabezados se eligieron por tamaño y la lista de encabezados no tiene sentido — causa: h3 usado porque «se ve más pequeño». Corrección: elegir el nivel por la estructura y dar tamaño con CSS.

Límites y cuándo no aplica

Las clases no fijan un límite propio para este término. Los límites del tema donde se enseña (SE-229 — Plataforma web, HTML semántico y CSS) son: Las definiciones son operativas para esta clase y deben contrastarse con las especificaciones enlazadas al final. Se ejecutaron tres experimentos con datos sintéticos en Windows y Ubuntu (WSL2) con resultados idénticos. No se midió a ninguna persona ni se usó un lector de pantalla: la página, las once mutaciones, la paleta y la simulación de especificidad son construcciones del autor. La siguiente clase pregunta qué ocurre cuando el documento deja de ser estático y un programa en JavaScript lo modifica en respuesta a eventos.
