Definición

Instancia resuelta sin llamada recursiva.

Definición de trabajo de SE-053 — Recursión, inducción y razonamiento estructural.

El programa usa el término con matices según la clase; el sentido principal es el anterior y los demás lo precisan:

  • En SE-063 — Iteración, recursión y recorridos: Entrada resuelta sin nueva recursión.

Por qué importa

La clase donde se define, SE-053 — Recursión, inducción y razonamiento estructural, existe con este propósito: la clase existe para relacionar definición recursiva, caso base, progreso e inducción.

Cómo funciona

Según SE-053 — Recursión, inducción y razonamiento estructural:

Una estructura recursiva se define mediante casos base y constructores que contienen estructuras menores. Un árbol vacío o hoja es base; un nodo con hijos combina subárboles. La definición excluye ciclos; si el dominio admite grafos, se requiere memoria de visitados.

Según SE-053 — Recursión, inducción y razonamiento estructural:

Elimina el caso base o llama recursivamente con el mismo nodo. Observa no terminación controlada por límite; identifica qué medida dejó de disminuir y repara el contrato.

Ejemplo

La clase no ilustra este término por separado; el ejemplo de su tema está en la sección «Ejemplo profesional» de SE-053 — Recursión, inducción y razonamiento estructural:

El modelo de decisión diagnóstica recorre el grafo de hipótesis con una pila explícita, límite de profundidad y conjunto de visitados. La especificación explica que un ciclo es error del modelo; no se oculta devolviendo silenciosamente una lista parcial.

Errores y confusiones comunes

Errores que las clases asocian con este término (síntoma → causa → corrección):

  • La demostración «funciona» con ejemplos pero no es válida — causa: se probó en lugar de demostrar. Corrección: escribir caso base, hipótesis y paso. (SE-053)
  • El caso base no se alcanza nunca — causa: el argumento no se acerca al base. Corrección: definir la medida que decrece. (SE-053)

Límites y cuándo no aplica

Las clases no fijan un límite propio para este término. Los límites del tema donde se enseña (SE-053 — Recursión, inducción y razonamiento estructural) son: Las definiciones fijan el uso en el modelo de decisión diagnóstica. Si una fuente usa otra convención, documenta la traducción. Una palabra definida no equivale a una propiedad demostrada. Inducción demuestra una propiedad del modelo, no corrige una especificación equivocada. La próxima clase combina contrato, invariante y variante para demostrar corrección y terminación.
