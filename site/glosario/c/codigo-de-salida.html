Definición

Cero indica éxito contractual; valores no cero clasifican uso inválido, datos rechazados, dependencia fallida o error interno según matriz publicada.

Definición de trabajo de SE-113 — CLI, flags, configuración y códigos de salida.

El programa usa el término con matices según la clase; el sentido principal es el anterior y los demás lo precisan:

  • En SE-029 — Terminales, shells y composición de comandos: Valor discreto con significado documentado para el proceso padre.
  • En SE-028 — Procesos, señales, servicios y tareas programadas: Valor con el que un proceso comunica una categoría de resultado.
  • En SE-072 — Proyecto: herramienta de línea de comandos probada: Entero que comunica resultado al proceso llamador.
  • En SE-220 — Códigos de salida, errores y diagnóstico: Entero con que un proceso informa al padre cómo terminó; 0 es éxito por convención.

Errores y confusiones comunes

Errores que las clases asocian con este término (síntoma → causa → corrección):

  • Un --help o un error de uso devuelve un código inesperado — causa: no se documentaron los códigos de salida. Corrección: tabla de códigos en el README y una prueba por cada valor. (SE-113)

Límites y cuándo no aplica

Lo que las clases dicen sobre dónde deja de valer este término:

  • El código de salida es la parte de una CLI que el sistema operativo y la integración continua interpretan sin leer una palabra. (SE-113)
