Definición

Cold/warm distingue estados inicial y estabilizado según protocolo.

Tomado del glosario de SE-023 — Taller: observar un programa desde el código hasta la máquina.

Por qué importa

La clase donde se define, SE-023 — Taller: observar un programa desde el código hasta la máquina, existe con este propósito: la clase existe para integrar las capas del computador en una explicación causal que separe observación, inferencia e hipótesis.

Cómo funciona

SE-023 — Taller: observar un programa desde el código hasta la máquina usa este término dentro de otro tema, sin una sección propia. El contexto en que aparece: consulta la clase para el mecanismo completo.

Errores y confusiones comunes

Ningún error de las clases nombra este término; estos son los errores frecuentes del tema donde se enseña (SE-023 — Taller: observar un programa desde el código hasta la máquina) son:

  • colección de capturas — causa: falta pregunta y ruta. Corrección: enlaza evidencia a transición.
  • variante produce otro resultado — causa: invariante no comprobado. Corrección: verifica hash antes de comparar recursos.

Límites y cuándo no aplica

Ninguna clase fija un límite propio para este término; estos son los límites del tema donde se enseña (SE-023 — Taller: observar un programa desde el código hasta la máquina) son: No observa energía, contadores físicos ni producción. SE-024 exige diseñar una investigación propia.
