Definición

Petición OPTIONS que el navegador envía para saber si el servidor permite una petición no simple.

Definición de trabajo de SE-236 — Seguridad del navegador y políticas de contenido.

Por qué importa

La clase donde se define, SE-236 — Seguridad del navegador y políticas de contenido, existe con este propósito: la clase existe para que entiendas qué defiende el navegador por sí mismo (el aislamiento por origen), qué dejas abierto al incluir datos ajenos en una página y qué políticas puedes declarar para reducir el daño (codificación por contexto, política de seguridad de contenido, atributos de cookie, comprobación de origen), de modo que «hemos añadido seguridad» sea una afirmación con casos probados y límites declarados.

Cómo funciona

SE-236 — Seguridad del navegador y políticas de contenido usa este término dentro de otro tema, sin una sección propia. El contexto en que aparece: Las definiciones son operativas para esta clase y deben contrastarse con las especificaciones enlazadas al final.

Errores y confusiones comunes

Ningún error de las clases nombra este término; estos son los errores frecuentes del tema donde se enseña (SE-236 — Seguridad del navegador y políticas de contenido) son:

  • Un nombre ejecuta código en un atributo — causa: atributo sin comillas con escape genérico. Corrección: poner comillas y usar la codificación del contexto.
  • Un enlace ejecuta javascript: al pulsarlo — causa: dirección aceptada sin validar el esquema. Corrección: permitir solo http, https y mailto y codificar.
