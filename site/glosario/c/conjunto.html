Definición

Colección definida por pertenencia.

Definición de trabajo de SE-051 — Conjuntos, relaciones, funciones y grafos.

Por qué importa

La clase donde se define, SE-066 — Colecciones y transformación de datos, existe con este propósito: la clase existe para seleccionar colecciones y transformaciones según orden, unicidad, acceso, memoria y mutabilidad.

Cómo funciona

Según SE-066 — Colecciones y transformación de datos, en la sección «Conjunto»:

Un set representa pertenencia única y ofrece unión, intersección y diferencia. No promete un orden estable para presentación. Es ideal para IDs visitados o tags; convertir una lista a set elimina duplicados sin explicar cuál registro conservar.

Ejemplo

Ejemplo de SE-066 — Colecciones y transformación de datos (sección «Ejemplo mínimo»):

Dado un conjunto de pruebas con IDs repetidos y tags, crea: secuencia original, índice único, conjunto de tags y lista elegible ordenada por costo. Declara qué ocurre con duplicados.

Errores y confusiones comunes

Errores que las clases asocian con este término (síntoma → causa → corrección):

  • El recorrido no termina — causa: no hay conjunto de visitados o medida decreciente. Corrección: registrar los nodos visitados y acotar los pasos. (SE-051)
  • Se usa una lista donde se pregunta «¿ya está?» — causa: estructura equivocada para la consulta. Corrección: cambiar a conjunto o mapa y medir. (SE-051)

Límites y cuándo no aplica

Lo que las clases dicen sobre dónde deja de valer este término:

  • Dónde deja de valer: la medición es el peor caso de la lista (elemento al final) y en CPython; con claves de hash costosas o con muchas colisiones el conjunto se degrada. (SE-066)
  • Un conjunto agrupa elementos por pertenencia, sin orden ni duplicados. (SE-051)
