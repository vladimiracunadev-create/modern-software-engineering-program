Definición

Identificadores de traza y de span que viajan con la petición y permiten enlazar spans.

Definición de trabajo de SE-496 — Trazas distribuidas y contexto.

Por qué importa

La clase donde se define, SE-496 — Trazas distribuidas y contexto, existe con este propósito: la clase existe para que expliques cómo una traza sigue una petición a través de varios servicios, qué hay que hacer en cada frontera para que no se rompa, cómo se lee la ruta crítica para saber qué optimizar y qué se pierde al muestrear.

Cómo funciona

SE-496 — Trazas distribuidas y contexto usa este término dentro de otro tema, sin una sección propia. El contexto en que aparece: Las definiciones son operativas para la API de entregas. No convierten términos con una historia más amplia en sinónimos y deben contrastarse con la documentación primaria enlazada al final.

Ejemplo

Contexto concreto en el que aparece el término, de la sección «Ejemplo profesional» de SE-496 — Trazas distribuidas y contexto:

Supón, como caso hipotético de la plataforma y no como medición, que el equipo hace el inventario de fronteras de la API de entregas: pasarela → API (HTTP, propaga solo), API → cola (el cliente de mensajería no copia propiedades), cola → trabajador (el trabajador lee el mensaje sin contexto), trabajador → hilo de procesamiento de archivos (grupo de hilos sin contexto) y trabajador → almacenamiento (HTTP, propaga solo). Tres de las cinco fronteras necesitan trabajo explícito.

Errores y confusiones comunes

Ningún error de las clases nombra este término; estos son los errores frecuentes del tema donde se enseña (SE-496 — Trazas distribuidas y contexto) son:

  • Hay trazas huérfanas de 3 segundos — causa: contexto perdido en un grupo de hilos o en una cola. Corrección: copiar el contexto explícitamente y probar la frontera.
  • Una traza está completa pero la mejora no llega — causa: se optimizó un span fuera de la ruta crítica. Corrección: calcular la ruta crítica antes de elegir.

Límites y cuándo no aplica

Ninguna clase fija un límite propio para este término; estos son los límites del tema donde se enseña (SE-496 — Trazas distribuidas y contexto) son: Las definiciones son operativas para la API de entregas. No convierten términos con una historia más amplia en sinónimos y deben contrastarse con la documentación primaria enlazada al final. Se ejecutaron tres experimentos con tiempo virtual y semillas fijas en Windows y Ubuntu (WSL2) con resultados idénticos.
