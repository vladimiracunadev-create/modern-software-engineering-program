Definición

Evaluación que omite operandos innecesarios.

Definición de trabajo de SE-062 — Control de flujo y decisiones.

Por qué importa

La clase donde se define, SE-062 — Control de flujo y decisiones, existe con este propósito: la clase existe para diseñar control de flujo desde decisiones del dominio y caminos verificables.

Cómo funciona

Según SE-062 — Control de flujo y decisiones, en la sección «Cortocircuito»:

and deja de evaluar al encontrar falso y or al encontrar verdadero; además devuelven operandos, no siempre bool. El cortocircuito permite comprobar value is not None and value >= 0, pero no debe esconder una llamada con efectos en la segunda condición.

Ejemplo

La clase no ilustra este término por separado; el ejemplo de su tema está en la sección «Ejemplo profesional» de SE-062 — Control de flujo y decisiones:

La CLI diagnóstica separa validación de clasificación. Una duración inválida genera INPUT_INVALID; un fallo de protocolo conserva su categoría; solo resultados ok se comparan con presupuesto. Así las métricas no cuentan errores de datos como degradación real.

Errores y confusiones comunes

Errores que las clases asocian con este término (síntoma → causa → corrección):

  • AttributeError solo con ciertos datos — causa: guarda en orden inverso, sin cortocircuito protector. Corrección: poner primero la comprobación is not None. (SE-062)

Límites y cuándo no aplica

Lo que las clases dicen sobre dónde deja de valer este término:

  • El cortocircuito permite comprobar value is not None and value >= 0, pero no debe esconder una llamada con efectos en la segunda condición. (SE-062)
