Definición

Almacenar hoy datos cifrados para descifrarlos cuando exista hardware capaz.

Definición de trabajo de SE-284 — Computación cuántica para ingenieros de software.

Por qué importa

La clase donde se define, SE-284 — Computación cuántica para ingenieros de software, existe con este propósito: la clase existe para que un ingeniero de software pueda leer una afirmación sobre computación cuántica (un titular, una propuesta de un proveedor, una exigencia de cumplimiento) y decidir qué parte es verificable, qué parte es especulación y qué decisión concreta le cambia.

Cómo funciona

Según SE-284 — Computación cuántica para ingenieros de software:

Qué sí: un ordenador cuántico suficientemente grande y con corrección de errores rompería RSA, Diffie-Hellman y las curvas elípticas con el algoritmo de Shor; debilitaría la criptografía simétrica y las funciones de resumen con Grover (se compensa con más bits); y podría simular sistemas cuánticos (química, materiales), que es el uso para el que fue propuesto. Qué no: no acelera la mayoría de las cargas de software (bases de datos, web, procesamiento de texto, entrenamiento de modelos de lenguaje), no «prueba todas las posibilidades a la vez» y no existe hoy un dispositivo que ejecute Shor contra claves reales.

Errores y confusiones comunes

Límites y cuándo no aplica

Lo que las clases dicen sobre dónde deja de valer este término:

  • Qué hacer ya: porque un adversario puede guardar hoy datos cifrados con claves que se romperían después (la amenaza llamada «cosechar ahora, descifrar después»), la decisión es de inventario y de migración criptográfica, no de comprar hardware cuántico. (SE-284)
