Definición

Resultado de una prueba que cambia según qué pruebas se ejecutaron antes.

Definición de trabajo de SE-428 — Datos deterministas y gestión de fixtures.

Por qué importa

La clase donde se define, SE-428 — Datos deterministas y gestión de fixtures, existe con este propósito: la clase existe para que prepares el estado de cada prueba de forma que el resultado dependa solo del código y de los datos declarados, y para que identifiques y elimines las fuentes de no determinismo (orden de ejecución, azar, hora, identificadores, orden de colecciones).

Cómo funciona

SE-428 — Datos deterministas y gestión de fixtures usa este término dentro de otro tema, sin una sección propia. El contexto en que aparece: Las definiciones son operativas para la plataforma de entregas y deben contrastarse con la documentación primaria enlazada al final.

Errores y confusiones comunes

Ningún error de las clases nombra este término; estos son los errores frecuentes del tema donde se enseña (SE-428 — Datos deterministas y gestión de fixtures) son:

  • Las pruebas pasan una a una y fallan juntas — causa: estado compartido mutable. Corrección: transacción con retroceso o base nueva por prueba.
  • Una prueba falla una vez de cada diez — causa: datos aleatorios sin semilla o propiedad mal enunciada. Corrección: registrar la semilla y revisar la propiedad.

Límites y cuándo no aplica

Ninguna clase fija un límite propio para este término; estos son los límites del tema donde se enseña (SE-428 — Datos deterministas y gestión de fixtures) son: Las definiciones son operativas para la plataforma de entregas y deben contrastarse con la documentación primaria enlazada al final. Se ejecutaron tres experimentos con una base SQLite en memoria, una propiedad con datos sintéticos y procesos locales en Windows y Ubuntu (WSL2) con salidas idénticas salvo las cifras que dependen del sistema o de la ejecución, declaradas arriba. Cinco de las doce pruebas dependen del estado compartido por diseño, y la propiedad falla por un efecto del redondeo escogido por el autor.
