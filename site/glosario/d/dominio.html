Por qué importa

En SE-050 — Lógica proposicional, predicados e inferencia, el tema «dominio» importa porque ¿qué entradas y estados existen?

Cómo funciona

Según SE-050 — Lógica proposicional, predicados e inferencia:

Un predicado depende de variables: responde(host, prueba). para todo exige cubrir el dominio declarado; existe se demuestra con un testigo. Pasar de «falló en un cliente» a «falla para todos» cambia el cuantificador sin evidencia.

Según SE-050 — Lógica proposicional, predicados e inferencia:

Aplica el mecanismo a otro dominio y conserva la estructura del argumento, no los nombres del modelo de decisión diagnóstica. Explica qué dominio, invariante o medida cambia. Si el razonamiento deja de funcionar, identifica el supuesto que pertenecía al caso original.

Ejemplo

Ejemplo de SE-052 — Invariantes, precondiciones y poscondiciones (sección «Preguntas frecuentes»):

No. Es una comprobación exhaustiva de un dominio acotado: conclusiva para ese dominio y evidencia para el resto. La hipótesis de «lo pequeño representa lo grande» se declara y se revisa.

Errores y confusiones comunes

Errores que las clases asocian con este término (síntoma → causa → corrección):

  • El bucle de búsqueda no termina en un borde — causa: la variante no decrece. Corrección: ajustar la actualización y probar el dominio pequeño. (SE-052)
  • La prueba pasa con ejemplos y falla con otros — causa: muestra no representativa. Corrección: enumerar un dominio pequeño completo. (SE-052)
  • «Es óptimo» tras probar tres casos — causa: muestra pequeña. Corrección: buscar contraejemplos en un dominio acotado. (SE-056)

Límites y cuándo no aplica

Lo que las clases dicen sobre dónde deja de valer este término:

  • Dónde deja de valer: solo cubre dominios finitos y enumerables. (SE-050)
  • Aplica el mecanismo a otro dominio y conserva la estructura del argumento, no los nombres del modelo de decisión diagnóstica. (SE-050)
