Definición

Asociación entre un nombre y un objeto del sistema de archivos.

Definición de trabajo de SE-026 — Sistemas de archivos, rutas, enlaces y metadatos.

Por qué importa

La clase donde se define, SE-026 — Sistemas de archivos, rutas, enlaces y metadatos, existe con este propósito: la clase existe para razonar sobre identidad de archivos mediante rutas, enlaces, metadatos y resolución.

Cómo funciona

SE-026 — Sistemas de archivos, rutas, enlaces y metadatos no desarrolla este término en una sección propia. Lo usa como pieza de su tema: consulta la clase para el mecanismo completo.

Ejemplo

La clase no ilustra este término por separado; el ejemplo de su tema está en la sección «Ejemplo profesional» de SE-026 — Sistemas de archivos, rutas, enlaces y metadatos:

Un actualizador escribe sobre el archivo final y se interrumpe, dejando JSON truncado. El equipo cambia a temporal en el mismo volumen, valida el contenido y reemplaza según la garantía documentada. Mantiene copia o recuperación porque atomicidad no equivale a persistencia ante toda falla.

Errores y confusiones comunes

Las clases no registran un error exclusivo de este término. Los errores frecuentes del tema donde se enseña (SE-026 — Sistemas de archivos, rutas, enlaces y metadatos) son:

  • El archivo se busca en lugares distintos — causa: se confundió directorio del script con directorio de trabajo. Corrección: elegir una base explícita y mostrarla en diagnóstico.
  • Una ruta portable se construye reemplazando / — causa: se trataron rutas como cadenas. Corrección: usar la biblioteca de rutas y probar raíces, volúmenes y UNC.

Límites y cuándo no aplica

Las clases no fijan un límite propio para este término. Los límites del tema donde se enseña (SE-026 — Sistemas de archivos, rutas, enlaces y metadatos) son: No cubrimos recuperación forense, sistemas distribuidos ni todas las garantías de cada sistema de archivos. Una ruta resoluble todavía puede estar prohibida. La próxima clase incorpora identidad, grupos, permisos y elevación para explicar esa decisión.

Fuentes

Fuentes de las clases donde se enseña (cada una respalda el mecanismo que su clase indica):

  • The Open Group — Pathname Resolution — define el contrato portable de procesos, rutas, entorno o shell que se contrasta entre sistemas.
  • Microsoft Learn — Naming Files, Paths, and Namespaces — documenta el comportamiento de Windows o PowerShell que se compara con el contrato POSIX.
  • Python documentation — pathlib — define la semántica y los límites de la API de Python utilizada en el experimento.
  • Apple Platform Deployment — File system basics — delimita el contrato técnico que debe cumplirse al razonar sobre identidad de archivos mediante rutas, enlaces, metadatos y resolución.
