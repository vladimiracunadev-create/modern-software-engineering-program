Definición

Dominio de ejecución restringido donde viven aplicaciones y servicios no privilegiados.

Definición de trabajo de SE-025 — Windows, Linux, macOS y sus modelos operativos.

Por qué importa

La clase donde se define, SE-025 — Windows, Linux, macOS y sus modelos operativos, existe con este propósito: la clase existe para comparar Windows, Linux y macOS por contratos observables y no por estereotipos.

Cómo funciona

Según SE-025 — Windows, Linux, macOS y sus modelos operativos:

El kernel ejecuta con privilegios para administrar memoria, planificación, interrupciones y dispositivos. Las aplicaciones normales viven en espacio de usuario con autoridad limitada. El cruce se realiza mediante interfaces controladas; no es una llamada de función ordinaria aunque una biblioteca la haga parecer así.

Ejemplo

La clase no ilustra este término por separado; el ejemplo de su tema está en la sección «Ejemplo profesional» de SE-025 — Windows, Linux, macOS y sus modelos operativos:

Un instalador falla solo en equipos corporativos. La misma versión funciona en un equipo personal. El kit de diagnóstico multiplataforma detecta que la API existe y el binario coincide, pero la ejecución está bloqueada por una política. La corrección se dirige al canal autorizado de distribución; recompilar al azar no aborda el mecanismo.

Errores y confusiones comunes

Errores que las clases asocian con este término (síntoma → causa → corrección):

  • “Linux” aparece como una sola plataforma uniforme — causa: se confundió kernel con distribución y espacio de usuario. Corrección: registrar kernel, distribución, versión y herramientas relevantes por separado. (SE-025)

Límites y cuándo no aplica

Las clases no fijan un límite propio para este término. Los límites del tema donde se enseña (SE-025 — Windows, Linux, macOS y sus modelos operativos) son: Esta clase no enseña administración profunda de kernels ni promete que una API conserve idéntica conducta entre versiones. Tampoco demuestra compatibilidad por detectar el nombre del sistema. La siguiente clase baja a una abstracción concreta —el sistema de archivos— donde pequeñas diferencias de rutas, enlaces y metadatos producen fallos muy visibles.
