Definición de trabajo de SE-612 — Proyecto: sistema de ML operable con evidencia.

Por qué importa

La clase donde se define, SE-612 — Proyecto: sistema de ML operable con evidencia, existe con este propósito: el proyecto existe para que entregues un sistema de aprendizaje automático que otra persona pueda operar, y para que lo demuestres con evidencia que se comprueba sola y no con un documento que se lee.

Cómo funciona

SE-612 — Proyecto: sistema de ML operable con evidencia no desarrolla este término en una sección propia. Lo usa como pieza de su tema: consulta la clase para el mecanismo completo.

Límites y cuándo no aplica

Las clases no fijan un límite propio para este término. Los límites del tema donde se enseña (SE-612 — Proyecto: sistema de ML operable con evidencia) son: El proyecto, las once comprobaciones, las cuatro variantes y los umbrales son construcciones del autor sobre datos sintéticos; la ficha y el runbook del laboratorio son marcadores. La puerta detecta los defectos sembrados y no los que nadie previó. No se evaluó ninguna plataforma de MLOps.
