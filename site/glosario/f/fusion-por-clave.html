Definición de trabajo de SE-364 — Transformación y orquestación idempotente con backfills.

Por qué importa

La clase donde se define, SE-364 — Transformación y orquestación idempotente con backfills, existe con este propósito: la clase existe para que construyas transformaciones de datos que se puedan ejecutar de nuevo sin miedo: tras un fallo a mitad, tras un reintento automático, tras corregir un dato de origen o tras descubrir un error de hace un mes.

Cómo funciona

SE-364 — Transformación y orquestación idempotente con backfills usa este término dentro de otro tema, sin una sección propia. El contexto en que aparece: consulta la clase para el mecanismo completo.

Límites y cuándo no aplica

Ninguna clase fija un límite propio para este término; estos son los límites del tema donde se enseña (SE-364 — Transformación y orquestación idempotente con backfills) son: Las particiones, el fallo y los retrasos son construcciones del autor; no se ejecutó ningún orquestador ni se midió una carga con millones de filas, y el tiempo de reemplazar una partición grande no se midió. El resultado «reemplazar y fusionar son idempotentes» vale con transacción o con una clave bien definida, y se comprobó solo para esos casos.
