Definición

Valor con hash estable utilizable como clave.

Definición de trabajo de SE-066 — Colecciones y transformación de datos.

Por qué importa

La clase donde se define, SE-066 — Colecciones y transformación de datos, existe con este propósito: la clase existe para seleccionar colecciones y transformaciones según orden, unicidad, acceso, memoria y mutabilidad.

Cómo funciona

Según SE-066 — Colecciones y transformación de datos:

Un dict asocia claves hashables con valores y conserva orden de inserción como propiedad del lenguaje moderno, pero su razón principal es acceso por clave. Una asignación repetida reemplaza el valor; para detectar duplicado se valida antes de insertar.

Según SE-066 — Colecciones y transformación de datos:

Lista para una secuencia que crece o se modifica; tupla para una secuencia fija o un registro ligero. La tupla comunica que no se va a modificar y es hashable si sus elementos lo son.

Errores y confusiones comunes

Ningún error de las clases nombra este término; estos son los errores frecuentes del tema donde se enseña (SE-066 — Colecciones y transformación de datos) son:

  • cambiar una fila cambia todas — causa: multiplicar una lista de listas comparte el objeto interno. Corrección: construir con una comprensión.
  • la copia «cambia sola» — causa: copia superficial de una estructura anidada. Corrección: copy.deepcopy o evitar la mutación.

Límites y cuándo no aplica

Lo que las clases dicen sobre dónde deja de valer este término:

  • Un frozenset expresa «solo pertenencia, no cambia» y es hashable, de modo que puede ser clave de un diccionario o miembro de otro conjunto. (SE-066)
  • La tupla comunica que no se va a modificar y es hashable si sus elementos lo son. (SE-066)
