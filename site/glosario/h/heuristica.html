Definición

Regla práctica sin garantía universal de optimalidad.

Definición de trabajo de SE-056 — Heurísticas, aproximación y límites computacionales.

Por qué importa

La clase donde se define, SE-056 — Heurísticas, aproximación y límites computacionales, existe con este propósito: la clase existe para usar heurísticas y aproximaciones declarando objetivo, garantía y contraejemplo.

Cómo funciona

Según SE-056 — Heurísticas, aproximación y límites computacionales, en la sección «Heurística»:

Una heurística usa conocimiento del dominio para encontrar rápido una solución plausible sin garantía general de calidad. Debe declarar casos adversos y fallback. elige prueba más barata falla si aporta poca información y obliga a muchas pruebas posteriores.

Ejemplo

Ejemplo de SE-056 — Heurísticas, aproximación y límites computacionales (sección «Preguntas frecuentes»):

No. Un algoritmo aproximado tiene una garantía demostrada (por ejemplo, nunca más de 1,5 veces el óptimo); una heurística no la tiene y solo se evalúa empíricamente.

Errores y confusiones comunes

Errores que las clases asocian con este término (síntoma → causa → corrección):

  • Una heurística se llama «aproximación» — causa: se confunde con garantía. Corrección: declarar si hay cota demostrada. (SE-056)

Límites y cuándo no aplica

Lo que las clases dicen sobre dónde deja de valer este término:

  • Una heurística usa conocimiento del dominio para encontrar rápido una solución plausible sin garantía general de calidad. (SE-056)
  • Un algoritmo aproximado tiene una garantía demostrada (por ejemplo, nunca más de 1,5 veces el óptimo); una heurística no la tiene y solo se evalúa empíricamente. (SE-056)
