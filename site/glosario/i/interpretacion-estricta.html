Definición

Conversión de texto a tipo que rechaza lo no reconocido en vez de adivinar.

Definición de trabajo de SE-219 — Configuración, flags, archivos y precedencia.

Por qué importa

La clase donde se define, SE-219 — Configuración, flags, archivos y precedencia, existe con este propósito: la clase existe para decidir de dónde obtiene una herramienta cada valor —valor por defecto, archivo, variable de entorno o flag—, en qué orden se imponen y cómo se comprueba que ese orden se cumple también en los casos extraños: valores vacíos, booleanos escritos de varias formas y secretos.

Cómo funciona

Según SE-219 — Configuración, flags, archivos y precedencia:

Una variable de entorno es una cadena. bool("false") es True porque la cadena no está vacía; int("٣") es 3 porque Python acepta dígitos de otros alfabetos; "1" == 1 es falso. Una interpretación estricta define el conjunto de formas aceptadas —por ejemplo, 1/true/yes/on y 0/false/no/off, sin distinguir mayúsculas ni espacios— y rechaza el resto con un error de uso en lugar de adivinar. Adivinar convierte un error de tipeo en un comportamiento silencioso.

Ejemplo

La clase no ilustra este término por separado; el ejemplo de su tema está en la sección «Ejemplo profesional» de SE-219 — Configuración, flags, archivos y precedencia:

notas carga el archivo de usuario (~/.config/notas/config.ini o el equivalente de Windows), después el del proyecto, lee las variables con prefijo NOTAS_, interpreta los booleanos con el analizador estricto y aplica los flags. El comando notas config --efectiva imprime cada opción con su valor y su fuente, con los secretos enmascarados. El token se lee de un archivo (--token-file) o de la entrada estándar; no existe --token.

Errores y confusiones comunes

Errores que las clases asocian con este término (síntoma → causa → corrección):

  • NOTAS_VERBOSE=false activa el modo detallado — causa: se aplicó bool() a una cadena. Corrección: interpretación estricta con conjunto cerrado. (SE-219)

Límites y cuándo no aplica

Lo que las clases dicen sobre dónde deja de valer este término:

  • Una interpretación estricta define el conjunto de formas aceptadas —por ejemplo, 1/true/yes/on y 0/false/no/off, sin distinguir mayúsculas ni espacios— y rechaza el resto con un error de uso en lugar de adivinar. (SE-219)
