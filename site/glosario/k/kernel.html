Definición

Componente privilegiado que arbitra recursos y expone operaciones controladas.

Definición de trabajo de SE-025 — Windows, Linux, macOS y sus modelos operativos.

Por qué importa

En SE-025 — Windows, Linux, macOS y sus modelos operativos, el tema «Protección» importa porque separa kernel y procesos de usuario

Cómo funciona

Según SE-025 — Windows, Linux, macOS y sus modelos operativos:

La abstracción no elimina el hardware. Lo representa con un contrato. Cuando una aplicación abre un archivo, una biblioteca prepara la operación, una llamada al sistema cruza la frontera de protección y el kernel consulta permisos y delega en el sistema de archivos o el controlador correspondiente.

Según SE-025 — Windows, Linux, macOS y sus modelos operativos:

Linux nombra el kernel; una instalación utilizable combina distribución, bibliotecas, herramientas y políticas.

Errores y confusiones comunes

Errores que las clases asocian con este término (síntoma → causa → corrección):

  • “Linux” aparece como una sola plataforma uniforme — causa: se confundió kernel con distribución y espacio de usuario. Corrección: registrar kernel, distribución, versión y herramientas relevantes por separado. (SE-025)

Límites y cuándo no aplica

Lo que las clases dicen sobre dónde deja de valer este término:

  • La Figura 1 las reúne: la aplicación puede haber construido mal la petición (se comprueba con los argumentos y la traza del propio programa), la biblioteca puede no ofrecer la función en esa versión, la API del sistema puede no existir en la plataforma, el kernel puede haber denegado la operación y el recurso puede no haber podido atenderla. (SE-025)
