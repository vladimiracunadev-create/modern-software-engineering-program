Definición

Crear, iniciar y adjuntar disparan comandos distintos.

Definición de trabajo de SE-104 — Dev Containers y entornos desechables.

Por qué importa

En SE-104 — Dev Containers y entornos desechables, el tema «Lifecycle y caché» importa porque crear, iniciar y adjuntar disparan comandos distintos.

Cómo funciona

Según SE-104 — Dev Containers y entornos desechables, en la sección «Lifecycle y caché»:

Crear, iniciar y adjuntar disparan comandos distintos. Un postCreate debe poder repetirse o declarar efectos. Cache acelera builds, pero una reconstrucción sin cache ayuda a descubrir dependencia oculta.

Ejemplo

Contexto concreto en el que aparece el término, de la sección «Ejemplo profesional» de SE-104 — Dev Containers y entornos desechables:

En el entorno reproducible de diagnóstico, una investigación conserva síntoma, entorno, reproducción, hipótesis, observaciones, causa, corrección y regresión. La implementación de esta clase debe conservar ese contrato aunque cambie la forma interna. El caso profesional no pregunta únicamente si produce una salida: pregunta quién puede producirla, qué estado observa, cómo falla y qué rastro permite disputar una decisión incorrecta.

Errores y confusiones comunes

Ningún error de las clases nombra este término; estos son los errores frecuentes del tema donde se enseña (SE-104 — Dev Containers y entornos desechables) son:

  • docker responde pero no se puede ejecutar nada — causa: el motor no está en marcha. Corrección: verificar el servidor con docker info.
  • La imagen cambia sin que el repositorio cambie — causa: etiqueta mutable. Corrección: fijar el digest.

Límites y cuándo no aplica

Ninguna clase fija un límite propio para este término; estos son los límites del tema donde se enseña (SE-104 — Dev Containers y entornos desechables) son: Las definiciones son operativas para el entorno reproducible de diagnóstico. No convierten términos con historia más amplia en sinónimos y deben contrastarse con la documentación primaria enlazada al final. Un contenedor estable no reduce automáticamente un fallo. La siguiente clase aplica delta debugging manual y control de variables para obtener un caso mínimo.
