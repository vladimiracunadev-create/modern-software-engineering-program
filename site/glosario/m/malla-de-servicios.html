Definición

Capa de proxies y control que gobierna el tráfico entre servicios.

Definición de trabajo de SE-341 — BFF, API gateway y service mesh.

Por qué importa

La clase donde se define, SE-341 — BFF, API gateway y service mesh, existe con este propósito: la clase existe para que distingas tres componentes que se confunden en casi todas las conversaciones de arquitectura: el API gateway, el BFF (backend for frontend) y la malla de servicios.

Cómo funciona

SE-341 — BFF, API gateway y service mesh usa este término dentro de otro tema, sin una sección propia. El contexto en que aparece: consulta la clase para el mecanismo completo.

Límites y cuándo no aplica

Ninguna clase fija un límite propio para este término; estos son los límites del tema donde se enseña (SE-341 — BFF, API gateway y service mesh) son: Los tamaños son de datos sintéticos, los tiempos de ronda son un modelo con supuestos del autor, el token es una demostración y el proxy es un reenviador mínimo. No se ejecutó ningún gateway, BFF ni malla real. El siguiente paso, SE-342, trata la identidad del inquilino: cómo se impide que los datos de un cliente aparezcan en la respuesta de otro y qué cuesta el aislamiento.
