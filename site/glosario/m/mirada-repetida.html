Definición

Comprobación de un resultado varias veces antes de decidir, que aumenta la probabilidad de declarar un efecto que no existe.

Definición de trabajo de SE-190 — Retrospectivas y mejora del sistema de trabajo.

Por qué importa

La clase donde se define, SE-190 — Retrospectivas y mejora del sistema de trabajo, existe con este propósito: la clase existe para que una retrospectiva produzca cambios que se terminan y se pueden evaluar, y no una lista de buenos propósitos: sabrás elegir cuántas acciones acordar según tu capacidad de mejora, cuántos datos necesitas para saber si una mejora funcionó y qué intervenciones mueven el sistema y cuáles solo piden más esfuerzo.

Cómo funciona

Según SE-190 — Retrospectivas y mejora del sistema de trabajo:

Puedes mirar, pero no decidir cada semana sin corregir por las miradas repetidas. La simulación mostró 19,7 % de falsas mejoras con doce miradas; fija una fecha o usa un método diseñado para evaluar de forma secuencial.

Errores y confusiones comunes

Errores que las clases asocian con este término (síntoma → causa → corrección):

  • Se declara éxito la primera vez que el gráfico baja — causa: miradas repetidas sin corrección. Corrección: fijar la fecha de decisión o usar un procedimiento secuencial. (SE-190)

Límites y cuándo no aplica

Lo que las clases dicen sobre dónde deja de valer este término:

  • Puedes mirar, pero no decidir cada semana sin corregir por las miradas repetidas. (SE-190)
