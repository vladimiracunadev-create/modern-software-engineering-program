Definición

Un módulo es unidad importable; un paquete organiza módulos y namespace.

Definición de trabajo de SE-112 — Paquetes, módulos y publicación.

Por qué importa

En SE-112 — Paquetes, módulos y publicación, el tema «Módulo, paquete e importación» importa porque un módulo es unidad importable; un paquete organiza módulos y namespace.

Cómo funciona

Según SE-112 — Paquetes, módulos y publicación, en la sección «Módulo, paquete e importación»:

Un módulo es unidad importable; un paquete organiza módulos y namespace. El layout src/ reduce import accidental desde checkout. La API pública se exporta deliberadamente; explorar internals por conveniencia crea consumidores frágiles.

Ejemplo

Contexto concreto en el que aparece el término, de la sección «Ejemplo profesional» de SE-112 — Paquetes, módulos y publicación:

En el producto reutilizable con SDK y CLI, un release contiene contrato público, artefactos inmutables, dependencias, procedencia, ejemplos, errores y ruta de migración. La implementación de esta clase debe conservar ese contrato aunque cambie la forma interna. El caso profesional no pregunta únicamente si produce una salida: pregunta quién puede producirla, qué estado observa, cómo falla y qué rastro permite disputar una decisión incorrecta.

Errores y confusiones comunes

Ningún error de las clases nombra este término; estos son los errores frecuentes del tema donde se enseña (SE-112 — Paquetes, módulos y publicación) son:

  • FileNotFoundError solo tras instalar — causa: el archivo de datos no está en package-data. Corrección: declararlo y comprobar el contenido de la rueda contra una lista esperada.
  • import json devuelve un objeto raro en un directorio concreto — causa: un json.py local tapa la biblioteca estándar. Corrección: renombrar el archivo y ejecutar con -I o -P para comprobar.

Límites y cuándo no aplica

Ninguna clase fija un límite propio para este término; estos son los límites del tema donde se enseña (SE-112 — Paquetes, módulos y publicación) son: Las definiciones son operativas para el producto reutilizable con SDK y CLI. No convierten términos con historia más amplia en sinónimos y deben contrastarse con la documentación primaria enlazada al final. Un paquete instalado todavía necesita una interfaz operable y estable. La siguiente clase diseña CLI, configuración, streams y códigos de salida como API pública.
