Definición

Valor especial para resultados no numéricos.

Definición de trabajo de SE-016 — Enteros, coma flotante, precisión y errores numéricos.

Por qué importa

La clase donde se define, SE-016 — Enteros, coma flotante, precisión y errores numéricos, existe con este propósito: la clase existe para evaluar precisión según representación, propagación del error y tolerancia ligada a la escala.

Cómo funciona

Según SE-016 — Enteros, coma flotante, precisión y errores numéricos:

IEEE 754 incluye infinitos, NaN y ceros con signo. NaN no es igual a sí mismo y puede propagarse; usarlo como dato faltante sin política mezcla ausencia con resultado indefinido. Validar entrada y salida evita que un valor especial atraviese decisiones que esperaban números finitos.

Según SE-016 — Enteros, coma flotante, precisión y errores numéricos:

NaN no es igual a sí mismo: float('nan') == float('nan') es falso. Para detectarlo usa math.isnan. Decide una política: rechazar la entrada, propagarlo y marcar el resultado como inválido, o sustituir un valor documentado. No uses NaN como valor faltante sin que el contrato lo diga, porque se mezclará con resultados indefinidos.

Errores y confusiones comunes

Errores que las clases asocian con este término (síntoma → causa → corrección):

  • NaN atraviesa el cálculo — causa: valores especiales no validados. Corrección: define entrada, propagación y rechazo. (SE-016)

Límites y cuándo no aplica

Lo que las clases dicen sobre dónde deja de valer este término:

  • NaN no es igual a sí mismo y puede propagarse; usarlo como dato faltante sin política mezcla ausencia con resultado indefinido. (SE-016)
