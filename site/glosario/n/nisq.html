Definición

Dispositivos ruidosos de escala intermedia, sin corrección de errores completa.

Definición de trabajo de SE-284 — Computación cuántica para ingenieros de software.

Por qué importa

La clase donde se define, SE-284 — Computación cuántica para ingenieros de software, existe con este propósito: la clase existe para que un ingeniero de software pueda leer una afirmación sobre computación cuántica (un titular, una propuesta de un proveedor, una exigencia de cumplimiento) y decidir qué parte es verificable, qué parte es especulación y qué decisión concreta le cambia.

Cómo funciona

SE-284 — Computación cuántica para ingenieros de software no desarrolla este término en una sección propia. Lo usa como pieza de su tema: consulta la clase para el mecanismo completo.

Errores y confusiones comunes

Límites y cuándo no aplica

Las clases no fijan un límite propio para este término. Los límites del tema donde se enseña (SE-284 — Computación cuántica para ingenieros de software) son: Todo se simuló de forma clásica con NumPy; no hubo acceso a hardware cuántico ni se ejecutó ningún SDK; la búsqueda de periodo es la de un número de dos cifras y el modelo de ruido es básico.
