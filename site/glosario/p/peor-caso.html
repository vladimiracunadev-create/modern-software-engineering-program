Definición

Máximo costo entre entradas del mismo tamaño.

Definición de trabajo de SE-055 — Complejidad temporal y espacial.

Por qué importa

La clase donde se define, SE-055 — Complejidad temporal y espacial, existe con este propósito: la clase existe para comparar crecimiento temporal y espacial antes de interpretar benchmarks.

Cómo funciona

Según SE-055 — Complejidad temporal y espacial:

El peor caso fija garantía; promedio exige distribución justificada; amortizado reparte secuencias de operaciones sin asumir azar. Presentar el caso favorable como promedio es un error. El modelo de decisión diagnóstica usa peor caso para deadline y medición para distribución observada.

Ejemplo

La clase no ilustra este término por separado; el ejemplo de su tema está en la sección «Ejemplo profesional» de SE-055 — Complejidad temporal y espacial:

El modelo de decisión diagnóstica modela recorrido O(V+E) y memoria O(V). El benchmark genera grafos dispersos y densos, separa construcción de consulta y registra versión. Un presupuesto cancela antes de agotar memoria y reporta salida parcial como incompleta.

Errores y confusiones comunes

Errores que las clases asocian con este término (síntoma → causa → corrección):

  • «Es O(1)» y un caso tarda mucho — causa: se confundió amortizado con peor caso. Corrección: declarar si el dato es promedio o peor caso. (SE-055)
