Definición

Afirmación con valor de verdad bajo una interpretación.

Definición de trabajo de SE-050 — Lógica proposicional, predicados e inferencia.

Por qué importa

La clase donde se define, SE-050 — Lógica proposicional, predicados e inferencia, existe con este propósito: la clase existe para usar lógica para comprobar validez de inferencias y hacer visibles supuestos.

Cómo funciona

Según SE-050 — Lógica proposicional, predicados e inferencia:

Una proposición es una afirmación evaluable como verdadera o falsa bajo una interpretación. «La red es mala» no tiene criterio; dns_outcome = timeout sí. La negación debe abarcar una afirmación definida: no observar respuesta no equivale automáticamente a observar ausencia.

Ejemplo

La clase no ilustra este término por separado; el ejemplo de su tema está en la sección «Ejemplo profesional» de SE-050 — Lógica proposicional, predicados e inferencia:

Las reglas del modelo de decisión diagnóstica no disparan acciones destructivas. Una conclusión incluye las premisas usadas, su vigencia y nivel de evidencia. Si falta una premisa, propone una prueba; si dos reglas concluyen estados incompatibles, eleva el conflicto en lugar de escoger silenciosamente.

Errores y confusiones comunes

Errores que las clases asocian con este término (síntoma → causa → corrección):

  • Una medición ruidosa se trata como booleano — causa: no se definió la proposición. Corrección: escribir el umbral, la ventana y el estadístico. (SE-050)

Límites y cuándo no aplica

Lo que las clases dicen sobre dónde deja de valer este término:

  • Dónde deja de valer: la lógica proposicional trata cada proposición como verdadera o falsa. (SE-050)
