Definición

Prueba que falla ante el defecto original y pasa con la corrección.

Definición de trabajo de SE-395 — Taller: reproducir una carrera y un fallo parcial.

El programa usa el término con matices según la clase; el sentido principal es el anterior y los demás lo precisan:

  • En SE-251 — Taller: reparar una API insegura e inconsistente: Prueba que falla si se reintroduce un defecto ya reparado.
  • En SE-467 — Taller: explotar y reparar un control aparente: Prueba que falla con el defecto y pasa con la corrección, y que se conserva para detectar su reaparición.

Por qué importa

La clase donde se define, SE-069 — Pruebas tempranas y diseño por ejemplos, existe con este propósito: la clase existe para usar ejemplos para descubrir particiones y propiedades antes de fijar implementación.

Cómo funciona

Según SE-069 — Pruebas tempranas y diseño por ejemplos, en la sección «Prueba de regresión»:

Al corregir un defecto se añade primero el caso que falla, se verifica rojo por la razón correcta, se corrige y se conserva. Cobertura indica ejecución, no calidad de oráculos. Se priorizan decisiones y riesgos.

Ejemplo

Ejemplo de SE-251 — Taller: reparar una API insegura e inconsistente (sección «Ejemplo profesional»):

El equipo recibe la API con los diez defectos y trabaja en seis pasos: escribe las tres suites; mide qué falla; repara por orden de riesgo (D3, D1, D10, D2, D4, D8, D6, D7, D9, D5); añade una prueba de regresión para cada reparación; reintroduce cada defecto y registra qué suite lo detecta; y publica la lista de defectos dormidos. Compara con el original en tres casos: un usuario normal, un integrador con un script y alguien que prueba la API sin permiso.

Errores y confusiones comunes

Errores que las clases asocian con este término (síntoma → causa → corrección):

  • Un defecto reparado reaparece — causa: no hay prueba de regresión que falle sin la reparación. Corrección: reintroducir el defecto y comprobar que falla. (SE-251)

Límites y cuándo no aplica

Lo que las clases dicen sobre dónde deja de valer este término:

  • No es necesariamente el mínimo global, pero suele ser lo bastante corto como para entenderse y para fijar la prueba de regresión. (SE-395)
  • Porque una prueba de regresión solo vale si falla cuando el defecto vuelve. (SE-251)
