Definición

Regla de decisión que usa una evaluación para publicar o retener.

Definición de trabajo de SE-549 — EDD: evaluaciones como especificación y puerta de release.

Por qué importa

La clase donde se define, SE-549 — EDD: evaluaciones como especificación y puerta de release, existe con este propósito: la clase existe para que trates una evaluación como lo que es, un instrumento de medida con ruido, y no como una prueba determinista con otro nombre.

Cómo funciona

SE-549 — EDD: evaluaciones como especificación y puerta de release no desarrolla este término en una sección propia. Lo usa como pieza de su tema: consulta la clase para el mecanismo completo.

Límites y cuándo no aplica

Las clases no fijan un límite propio para este término. Los límites del tema donde se enseña (SE-549 — EDD: evaluaciones como especificación y puerta de release) son: La simulación modela casos como lanzamientos independientes con probabilidades supuestas; no se evaluó ningún modelo ni producto real. El siguiente paso, SE-550, trata un flujo de trabajo concreto para agentes de código, ODD, con su evidencia declarada y los límites de su documentación.
