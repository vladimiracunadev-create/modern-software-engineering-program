Definición

¿qué debe ser cierto?

Es uno de los temas de SE-049 — Descomposición, abstracción y reconocimiento de patrones, donde se enseña como «regla».

Por qué importa

En SE-050 — Lógica proposicional, predicados e inferencia, el tema «regla» importa porque ¿qué debe ser cierto?

Cómo funciona

Según SE-050 — Lógica proposicional, predicados e inferencia:

Modus ponens aplica P y P→Q para obtener Q; modus tollens usa P→Q y no Q para obtener no P. Afirmar el consecuente y negar el antecedente son errores frecuentes. El modelo de decisión diagnóstica almacena premisas junto a fuente y momento, porque una regla válida con una premisa obsoleta produce una conclusión inútil.

Según SE-050 — Lógica proposicional, predicados e inferencia:

Las reglas del modelo de decisión diagnóstica no disparan acciones destructivas. Una conclusión incluye las premisas usadas, su vigencia y nivel de evidencia. Si falta una premisa, propone una prueba; si dos reglas concluyen estados incompatibles, eleva el conflicto en lugar de escoger silenciosamente.

Errores y confusiones comunes

Errores que las clases asocian con este término (síntoma → causa → corrección):

  • Una regla «todas pasan» se cumple sin ejecutar nada — causa: verdad vacía sobre un conjunto vacío. Corrección: comprobar que el conjunto no es vacío antes de afirmar. (SE-050)
  • Una prueba se debilita para que pase — causa: se trata como obstáculo. Corrección: revisar la regla o el modelo. (SE-060)
  • Se cambia el resultado esperado para que la prueba pase — causa: se trata la prueba como obstáculo. Corrección: revisar la regla o el modelo, no el resultado. (SE-052)

Límites y cuándo no aplica

Lo que las clases dicen sobre dónde deja de valer este término:

  • Es la falacia más frecuente en un diagnóstico: de «si DNS falla, el nombre no resuelve» no se sigue «si el nombre no resuelve, DNS falla»; el resolvedor local, una regla de red o un archivo hosts producen el mismo síntoma. (SE-050)
