Definición

El runtime ejecuta o soporta programas mediante memoria, carga, garbage collection, event loop o stdlib.

Definición de trabajo de SE-109 — Biblioteca, framework, runtime, plataforma y SDK.

El programa usa el término con matices según la clase; el sentido principal es el anterior y los demás lo precisan:

  • En SE-021 — Runtimes, máquinas virtuales y recolección de basura: Servicios que implementan ejecución de un lenguaje.
  • En SE-013 — Arquitectura básica de un computador moderno: Servicios que sostienen un programa durante ejecución.

Por qué importa

En SE-109 — Biblioteca, framework, runtime, plataforma y SDK, el tema «Runtime» importa porque el runtime ejecuta o soporta programas mediante memoria, carga, garbage collection, event loop o stdlib.

En SE-021 — Runtimes, máquinas virtuales y recolección de basura, el tema «Runtime» importa porque implementa servicios no escritos en cada programa

Cómo funciona

Según SE-109 — Biblioteca, framework, runtime, plataforma y SDK, en la sección «Runtime»:

El runtime ejecuta o soporta programas mediante memoria, carga, garbage collection, event loop o stdlib. Es una dependencia operacional distinta del paquete. Versiones compatibles deben incluir implementación y plataforma cuando afectan ABI o comportamiento.

Errores y confusiones comunes

Errores que las clases asocian con este término (síntoma → causa → corrección):

  • import mi_sdk tarda 300 ms y carga más de 100 módulos — causa: el __init__ importa un runtime completo aunque se use una función. Corrección: importar de forma perezosa dentro de la función o dividir en extras. (SE-109)
  • del = liberación física — causa: niveles confundidos. Corrección: habla de referencias y política del runtime. (SE-021)
  • una línea equivale a una instrucción — causa: se saltaron compilador y runtime. Corrección: traza representaciones intermedias. (SE-013)

Límites y cuándo no aplica

Lo que las clases dicen sobre dónde deja de valer este término:

  • Si el SDK necesita un runtime pesado solo para una función, esa función debería importarlo de forma perezosa o vivir en un subpaquete opcional. (SE-109)
  • Elimina una referencia; el efecto depende de referencias restantes, runtime y asignador. (SE-021)
