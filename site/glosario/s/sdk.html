Definición

Un sdk reduce fricción para integrar una capacidad: cliente, modelos, autenticación, ejemplos, tooling y documentación.

Definición de trabajo de SE-109 — Biblioteca, framework, runtime, plataforma y SDK.

Por qué importa

En SE-109 — Biblioteca, framework, runtime, plataforma y SDK, el tema «SDK» importa porque un SDK reduce fricción para integrar una capacidad: cliente, modelos, autenticación, ejemplos, tooling y documentación.

Cómo funciona

Según SE-109 — Biblioteca, framework, runtime, plataforma y SDK, en la sección «SDK»:

Un SDK reduce fricción para integrar una capacidad: cliente, modelos, autenticación, ejemplos, tooling y documentación. Debe representar el contrato remoto sin ocultar timeout, paginación o error. Puede incluir biblioteca y CLI, pero su promesa es experiencia coherente.

Ejemplo

Ejemplo de SE-109 — Biblioteca, framework, runtime, plataforma y SDK (sección «Ejemplo profesional»):

En el producto reutilizable con SDK y CLI, un release contiene contrato público, artefactos inmutables, dependencias, procedencia, ejemplos, errores y ruta de migración. La implementación de esta clase debe conservar ese contrato aunque cambie la forma interna. El caso profesional no pregunta únicamente si produce una salida: pregunta quién puede producirla, qué estado observa, cómo falla y qué rastro permite disputar una decisión incorrecta.

Errores y confusiones comunes

Errores que las clases asocian con este término (síntoma → causa → corrección):

  • Clasificar un producto por su nombre: «es un SDK porque se llama SDK» — causa: se clasificó por marketing y no por control ni contrato. Corrección: imprimir la pila desde un callback y decidir por quién ocupa el fondo. (SE-109)
  • import mi_sdk tarda 300 ms y carga más de 100 módulos — causa: el __init__ importa un runtime completo aunque se use una función. Corrección: importar de forma perezosa dentro de la función o dividir en extras. (SE-109)
  • import mi_sdk falla en CI sin credenciales — causa: el módulo lee variables de entorno o abre red al importarse. Corrección: mover los efectos a connect() y comprobar con un gancho de auditoría. (SE-109)

Límites y cuándo no aplica

Lo que las clases dicen sobre dónde deja de valer este término:

  • Lo que el SDK decide por defecto lo hereda cada consumidor sin saberlo. (SE-109)
