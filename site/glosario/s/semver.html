Definición

Semver exige declarar api pública: major para ruptura, minor para funcionalidad compatible y patch para corrección compatible, con reglas particulares antes de 1.

Definición de trabajo de SE-110 — SemVer, compatibilidad y contratos públicos.

Por qué importa

En SE-110 — SemVer, compatibilidad y contratos públicos, el tema «SemVer» importa porque SemVer exige declarar API pública: major para ruptura, minor para funcionalidad compatible y patch para corrección compatible, con reglas particulares antes de 1.

Cómo funciona

Según SE-110 — SemVer, compatibilidad y contratos públicos, en la sección «SemVer»:

SemVer exige declarar API pública: major para ruptura, minor para funcionalidad compatible y patch para corrección compatible, con reglas particulares antes de 1.0. El número comunica intención; no verifica que el cambio cumpla ni reemplaza política de soporte.

Errores y confusiones comunes

Errores que las clases asocian con este término (síntoma → causa → corrección):

  • Una versión SemVer con guion se rechaza al publicar — causa: no es una versión PEP 440 válida (1.0.0-alpha.beta). Corrección: normalizar al esquema de Python o cambiar de esquema y documentarlo. (SE-110)

Límites y cuándo no aplica

Lo que las clases dicen sobre dónde deja de valer este término:

  • 1.0.post1 > 1.0.0, un concepto que SemVer no define. (SE-110)
