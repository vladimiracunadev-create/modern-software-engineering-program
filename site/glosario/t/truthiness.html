Definición

Regla que convierte valores a contexto booleano.

Definición de trabajo de SE-062 — Control de flujo y decisiones.

Por qué importa

La clase donde se define, SE-062 — Control de flujo y decisiones, existe con este propósito: la clase existe para diseñar control de flujo desde decisiones del dominio y caminos verificables.

Cómo funciona

Según SE-062 — Control de flujo y decisiones:

if evalúa truthiness, que considera falsos 0, None y colecciones vacías. Esa conveniencia puede mezclar ausencia, cero válido y lista sin elementos. En reglas de dominio se prefieren comparaciones explícitas para que el lector sepa qué caso se trata.

Ejemplo

Contexto concreto en el que aparece el término, de la sección «Ejemplo profesional» de SE-062 — Control de flujo y decisiones:

La CLI diagnóstica separa validación de clasificación. Una duración inválida genera INPUT_INVALID; un fallo de protocolo conserva su categoría; solo resultados ok se comparan con presupuesto. Así las métricas no cuentan errores de datos como degradación real.

Errores y confusiones comunes

Ningún error de las clases nombra este término; estos son los errores frecuentes del tema donde se enseña (SE-062 — Control de flujo y decisiones) son:

  • clases mal asignadas justo en el límite — causa: <= y < intercambiados, sin prueba de frontera. Corrección: probar ambos lados de cada umbral.
  • if budget: responde igual con 0 y con None — causa: verdad de Python mezcla ausencia y cero. Corrección: comparar con is None y con 0 por separado.

Límites y cuándo no aplica

Ninguna clase fija un límite propio para este término; estos son los límites del tema donde se enseña (SE-062 — Control de flujo y decisiones) son: Estas definiciones describen el uso concreto en la CLI diagnóstica. Cuando Python permita varias conductas, el contrato del programa elige una y la hace visible con validación y pruebas. Las ramas secuenciales no modelan bien procesos largos ni estados concurrentes.
