Definición

Dato concreto manipulable por el programa.

Definición de trabajo de SE-061 — Valores, expresiones, tipos y variables.

Por qué importa

En SE-061 — Valores, expresiones, tipos y variables, el tema «valor» importa porque ¿qué representa y qué tipo tiene?

Cómo funciona

Según SE-061 — Valores, expresiones, tipos y variables:

Un valor es información concreta interpretada según un tipo: 800, 800.0 y '800' no son intercambiables. Enteros de Python tienen precisión arbitraria práctica limitada por memoria; float aproxima números binarios y no representa exactamente muchos decimales. Unidades y dominio no vienen incluidos en el tipo incorporado.

Según SE-061 — Valores, expresiones, tipos y variables:

Porque CPython reutiliza objetos enteros pequeños (medimos que 256 sí y 257 no). Es un detalle de implementación: comparar valores se hace con ==, e is queda para None.

Ejemplo

Ejemplo de SE-061 — Valores, expresiones, tipos y variables (sección «Ejemplo mínimo»):

Evalúa 0.1 + 0.2, bool('false'), 3 / 2, 3 // 2 y '3' * 2. Antes de ejecutar predice valor y tipo; después explica qué interpretación sería peligrosa en la CLI diagnóstica.

Errores y confusiones comunes

Errores que las clases asocian con este término (síntoma → causa → corrección):

  • --enabled false queda activado — causa: bool('false') es True (cadena no vacía). Corrección: parser explícito que acepte solo valores documentados. (SE-061)
  • el resultado de una función depende de llamadas anteriores — causa: valor por defecto mutable compartido. Corrección: None como centinela y crear el objeto dentro. (SE-064)
  • un valor negativo se clasifica como válido — causa: cadena sin rama de entrada inválida. Corrección: guarda inicial que rechace el dominio no admitido. (SE-062)

Límites y cuándo no aplica

Lo que las clases dicen sobre dónde deja de valer este término:

  • bool modela dos valores, pero no sirve para distinguir desconocido de falso. (SE-061)
  • return termina y entrega un valor; sin return explícito devuelve None. (SE-064)
